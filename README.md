# scRNA-seq Analysis of Glioma and PCNSL

This repository contains a Seurat-based single-cell RNA sequencing
analysis pipeline used in a Master's thesis project.

## Workflow
1. Quality control and filtering
2. Normalization and PCA
3. Clustering and UMAP visualization
4. Marker gene identification
5. Cell-type annotation

## Requirements
- R (>=4.2)
- Seurat (>=4.3)

## Usage
Run scripts sequentially from the `scripts/` directory.

## Data
Raw 10X Genomics data should be placed in `data/raw/`.
